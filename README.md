# 易卦研习 · 易经自习室

《易经》文化学习与术数应用的纯前端静态网站。无需后端、无需构建，打开即用。

## 功能模块

- **六十四卦图鉴**：文王卦序全收录，每卦配卦象、白话解读与类象卡，可逐卦解锁收藏。
- **万物归卦**：输入身边事物查它归于哪一卦，或选上下两象拼出六十四卦，训练取象思维。
- **闯关学习**：Duolingo 式关卡，从阴阳爻、八卦取到六十四卦、方位爻位，边玩边记。
- **三式应用**（可学可随时结合生活起局）：
  - **六爻纳甲**（京房纳甲法）：自动装卦、纳甲配支、六亲六神、世应、旬空月破、伏神。
  - **梅花易数**（邵雍心法）：年月日时 / 数字 / 字数 / 心动起卦，体用互变、五行生克断卦。
  - **奇门遁甲**（时家转盘·拆补法）：地盘三奇六仪、天盘九星、人盘八门、神盘八神四盘合一。

## 技术说明

- 原生 **HTML + CSS + ES Module**，无框架、无构建步骤。
- 干支历法（二十四节气、四柱、旬空、农历）、六爻 / 梅花 / 奇门三大引擎均为前端自研。
- 内容以张延生《易学入门》体系为主干，三式依《增删卜易》《梅花易数预测学》《奇门遁甲入门讲义》等经典体例整理，力求原真、不阉割。

## 本地预览

因浏览器安全策略，ES Module 不能用 `file://` 直接双击打开，需用本地服务器：

```bash
# 进入 web/ 目录后用任意静态服务器，例如：
python -m http.server 8081
# 浏览器访问 http://127.0.0.1:8081/
```

项目根目录已附 `start_server.bat`，双击即可启动本地服务器。

## 部署

本仓库即 GitHub Pages 站点，站点根目录为 `web/`。推送与发布流程见仓库内的 `deploy.sh`。
